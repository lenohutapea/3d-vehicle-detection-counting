        Hubungkan perangkat

        Jalankan perintah ini di Raspberry Pi yang terpasang di lokasi. Perangkat menanyakan tugas ke server setiap 5 detik.

        1. 1
          Salin program ke perangkat Berkas node_camera.py ada di folder centernet3d_bbox/node/. Unduh node_camera.py
        2. 2
          Jalankan perintah sesuai jenis kamera
          Alamat yang bisa dijangkau perangkat, misalnya domain Cloudflare Anda. Bukan 127.0.0.1.
          Lihat di manual atau aplikasi kamera. Hanya dipakai untuk menyusun perintah, tidak disimpan di server.
